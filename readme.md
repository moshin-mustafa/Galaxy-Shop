Week 1
Foundation

Project planning and UI
- Define the features and customer journey.
- Design the homepage, product cards, product details, login, cart, and checkout screens.
- Establish a responsive design system.
- Review the Express-to-PostgreSQL workflow.
Milestone: approved UI plan and database design.



Week 2
Catalog

Build the product experience
- Create the EJS page structure and shared layouts.
- Display phones and laptops from PostgreSQL.
- Add product details, categories, search, and filtering.
- Learn how frontend forms communicate with Express.
Milestone: working product catalog powered by the database.



Week 3
Accounts

Authentication and authorization
- Registration, login, and logout.
- Password hashing and session management.
- Protected customer and administrator routes.
- Server-side validation and access control.
Milestone: customers can securely access their accounts.



Week 4
Shopping

Cart and order management
- Add, remove, and update cart items.
- Validate stock and prices on the server.
- Design order and order-item records.
- Create orders reliably using database transactions.
Milestone: a customer can create and view an order.



Week 5
Admin

Store management
- Add, edit, and remove products.
- Manage stock and product categories.
- View orders and update their fulfillment status.
- Enforce administrator-only permissions.
Milestone: the store can be managed without manually editing the database.



Week 6
Payments

Payment integration
- Select a suitable payment provider.
- Integrate its test environment.
- Verify payment status through trusted server-side confirmation.
- Handle failed, cancelled, and repeated payment attempts.
Milestone: the test checkout flow works correctly.



Week 7
Security

Testing and hardening
- Test invalid inputs and unauthorized access.
- Check that customers cannot alter prices or access other customers' orders.
- Test stock conflicts and payment failure scenarios.
- Improve error handling and form feedback.
Milestone: the important user flows work reliably.



Week 8
Delivery

Deployment and presentation
- Deploy the application and configure environment variables.
- Document the database schema and architecture.
- Prepare test cases and a demonstration.
- Practise explaining the complete order and payment lifecycle.
Milestone: a demonstrable full-stack project you understand.
